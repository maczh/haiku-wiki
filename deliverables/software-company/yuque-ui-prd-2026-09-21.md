## 2. 产品定义

### Product Goals

1. **对齐语雀核心编辑体验**：目录树 hover 操作、快速新建、阅读折叠、块级操作四大交互达到语雀同类可用性，老用户零学习成本。
2. **不破坏现有稳定性**：dnd-kit 拖拽、右键菜单、自动保存（3s 防抖）、现有渲染管线零回归。
3. **按自身能力诚实映射**：语雀菜单项逐条映射到寄海文库已有/可低成本实现的 doc_type 与 Vditor 能力，无对应能力的不虚构承诺。

### User Stories

1. As a 知识库用户, I want 鼠标悬停目录树条目时出现「⋮」按钮，点开即可重命名/复制链接/置顶/删除等操作, so that 不必依赖右键也能快速完成文档管理。
2. As a 知识库用户, I want 悬停条目行尾点「+」直接选类型新建文档/表格/画板/分组, so that 新建动作在当前目录语境下一步完成。
3. As a 阅读者, I want 阅读长文档时 hover 标题出现折叠箭头、点击收起该章节, so that 快速跳读和聚焦感兴趣的段落。
4. As a Markdown 编辑者, I want hover 任意块左侧出现「⋮⋮」手柄，点击可删除/复制/剪切/缩进/转化为其他块类型/在下方添加新块, so that 无需记 Markdown 语法即可结构化编辑。
5. As a Markdown 编辑者, I want 选中块时出现格式弹层（H1–H6、列表、待办、高亮块、引用等）, so that 快速调整块级格式。

### 3.2 UI Design Draft

```
目录树条目（hover 态）：
│ 📄 门店内桌台状态MQTT消息格式说明        ⋮  + │
                                         │    └─ hover 显示，二者不互斥
「⋮」菜单（AntD Dropdown，与右键菜单同源）：
  重命名 / 编辑文档 / 复制链接 / 在新标签页打开
  ── 移出目录 ──
  复制… / 移动… / 导出… / 置顶文档
  ── 删除（红色，二次确认，进回收站）

「+」下拉：
  文档 / 表格 / 画板 / 思维导图 / 流程图
  ── 新建分组

阅读视图：
  ### 2.3 主要字段说明  ▾(hover 出现)   ← 点击折叠至下一个同级/更高级标题

编辑器（Vditor IR）：
  ⋮⋮ │ 项目复盘主要在于…        ← hover 块左侧手柄
   └─ 点击：转化为 > / 删除 / 复制 / 剪切 / 缩进 > / 复制链接 / 在下方添加 >
   └─ 选中块时：浮层 [H1 H2 H3 H4 H5 H6 | B 列表 待办 代码 | 高亮块 引用 折叠块]
```

交互约束：
- 「⋮」「+」hover 出现（CSS opacity/条件渲染），不占布局位，不干扰 dnd-kit 拖拽命中区。
- 编辑器 DOM 扩展不得修改 Vditor 内部状态机，所有内容变更须走可触发保存防抖的正常路径。
- 菜单打开时阻止拖拽事件冒泡，避免误触发排序。

### 3.3 Open Questions（需澄清）

1. **Q1 移动 API**：现有「移动到其他知识库」的接口是否支持目标 parent 指定为书内根级（即「移出目录」的落点）？若不支持需后端小改，请架构师评估。
2. **Q2 复制文档**：「复制…」的 duplicateDoc 是否已接前端入口？若无，本次一并补齐。
3. **Q3 Vditor 插入能力清单**：「在下方添加」与「转化为」的最终块类型清单，以架构师对 Vditor IR 源码级操作的可行性结论为准。
4. **Q4 块手柄实现路径**：直接操作 Vditor value（Markdown 源串定位替换，推荐）还是 DOM 改写 + 同步回 value？影响「复制/剪切/缩进」的实现顺序，请架构师定夺。
5. **Q5 复制链接格式**：深链 `/books/:bookId?docId=:id` 是否为阅读页实际消费的参数格式？请与现有路由确认。
