## 编辑模式 6 项 bug 修复（第二轮，本轮完成）

### 根因与修复
- **bugs #1-4（手柄/表格/代码块/斜杠菜单全裸）根因 = Crepe 主题基底 CSS 缺失**：库约定宿主必须先
  `@milkdown/crepe/theme/common/style.css + nord.css` 再引包内 style.css（typora 靠顺序覆盖）。
  原 crepe-theme.css 里是裸 `@import '@milkdown/kit/prose/...'` 等宿主解析不了的包 → Vite pre-transform
  ERROR → 模块图崩 → 白屏。修复：`~/.workbuddy/tmp/inline-crepe.mjs` 递归内联全部 @import
  （`@milkdown/kit/prose/X/style/Y.css → @milkdown/prose/lib/style/Y.css`，katex/virtual-cursor 从
  库 node_modules 内联）产出零外部 @import 的 `crepe-theme.css`（97KB，84 处 .ProseMirror）。
- **bug #5（大纲右边栏丢失）根因 = vendored 包里的 OutlinePanel 被 tree-shake**：bundle 里
  `aE as OutlinePanel` 导出存在但 `outline-panel`/`outline-list` 字符串 0 命中 —— 组件实现没被打进去，
  渲染即抛 "Element type is invalid" 连带卸载整棵编辑树（bisect：裸 MdEditor 挂载✓，+OutlinePanel 不挂）。
  库的 useEditorStore/useTranslation 其实是模块级 zustand 单例（无 Context 依赖），不是问题所在。
  **修复 = 宿主自建 `web/src/components/OutlinePanel.tsx`**：自含 ATX 标题解析（#{1,6}、跳过 ``` 围栏，
  复刻库 utils/outline.ts 语义），markdown prop 驱动（TypoMdEditor 维护 markdown state，
  onUpdateModelValue 回灌），getContainer 传入 `.milkdown` 包裹层作用域化滚动定位，点击滚到标题+高亮闪烁。
  ⚠️ `<li>` 必须带 `className="hk-outline-item"`（首轮漏写导致探针 0 命中、差点误判未渲染——实际在渲染）。
- **bug #6（阅读态代码块浅灰）**：`toHtml` 产出完整 HTML 文档，`<head>` 里自带
  `pre,code{background:#f6f8fa}`，但 MarkdownView 只取 `doc.body.innerHTML` 把 head 样式丢了；
  阅读态底色由 markdown-body.css/reader.css 决定（原 #f8fafc）。两处统一改成显式 `#f6f8fa`。
  `hljs` class 是 highlighter 运行时加的（bundle 静态 grep 不到，别被误导）；行内 code 无 hljs 类。
