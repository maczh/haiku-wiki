# 2026-09-30

## 思维导图换引擎：simple-mind-map → mindmap-vite（分支 v1-mm）

用户要求：基于 v1 建 `v1-mm`，把思维导图组件整换成自建 `mindmap-vite`，
功能（编辑/阅读/分享/H5）不变，**后端与存储格式不变**。两项决策：
① 组件缺的能力（节点图片/标签/LaTeX/关联线/外框/概要）**在组件源码补齐**；
② 接入方式 **源码 vendor 进仓库**。

### 关键约定
- 适配层 `web/src/lib/mindmap.smm.ts` 是 SMM 契约 ⇄ `MindNode` 的唯一转换口；
  `lib/mindmap.ts` 只再导出契约 + parse/stringify。存 `version:2 / root{data,children} / layout / theme`。
- 组件用 `forwardRef + useImperativeHandle` 暴露 `MindMapApi`，宿主工具条不需要知道底层引擎。
- H5 原生无级缩放走新接口 `getView()/setView()`（等价旧 `view.scale/x/y + transform()`）。
- 保存必须 `stringifyMindmap(mindNodeToSmm(tree), theme, layout)` —— 直接传 MindNode 会静默退化成空根。

### 踩到的坑（下次直接避开）
- 相对导入层级极易写错：`src/components/reader/X.tsx` 用 `../mindmap-vite/...`，
  `src/components/editor/mindmap/X.ts` 用 `../../mindmap-vite/...`，
  `src/components/editor/X.tsx` 用 `../mindmap-vite/...`。
- MindMap.tsx 300 行后的 `editable` 与 props 同名，全部改名 `editableNow`。
- MindNodeStyle 原本没有 `borderRadius`，已补（渲染 `rx` 按宽高一半内敛），否则侧栏「圆角」是空操作。
- 补类型要同时改 `types.ts` **和** `components/MindMap/index.ts` 的 export 列表，否则 TS2724。

### 环境（重要，全是踩坑得来）
- **真 HOME 是 `/home/Macro`（大写 M）**。写成 `/home/macro`（小写）会让 Chrome 起不来：
  报 `Failed to create headless user data directory container` → `FATAL base/path_service.cc:264
  Failed to get the path for 1001`。用对 HOME 后无头 Chrome 完全正常。
- 起静态服务 + 跑 Chrome 必须放**同一条命令**：后台起的 `python3 -m http.server` 跨工具调用会被沙箱回收，
  再访问就 `ERR_CONNECTION_REFUSED`。
- 完整可用姿势（`HOME=/home/Macro`）：
  `(python3 -m http.server 8899 --bind 127.0.0.1 & SRV=$!; sleep 2;
  /opt/google/chrome/chrome --headless=new --no-sandbox --disable-gpu --disable-dev-shm-usage
  --hide-scrollbars --window-size=960,2300 --user-data-dir=/home/Macro/hk-tmp/cpX
  --virtual-time-budget=8000 --screenshot=shot.png http://127.0.0.1:8899/index.html; kill $SRV)`
  配 dump-dom 抓 `<pre id="result">` 即可做断言；截图高度=窗口高度。
- 组件自测页：临时入口放 `web/src/__mm_x.tsx`（放这里才能解析 react），
  `node_modules/.bin/esbuild x.tsx --bundle --format=iife --jsx=automatic --loader:.css=css
  --loader:.woff=dataurl --loader:.woff2=dataurl --loader:.ttf=dataurl --outfile=...`，
  页面里 setTimeout 1.2s 后把统计写进 `<pre id="result">`，`--virtual-time-budget` >= 8000。
  纯逻辑校验走 `--platform=node --format=cjs` + 托管 node 跑断言。
- esbuild 会 tree-shake 掉没用到的顶层 const，**别靠「bundle 里搜到某行」判断源码改没改**。
- `tools/verify/*` 依赖的 `agent-browser` 确实没装在 node workspace，别直接跑套件。
