## 本轮修掉的 4 个真实缺陷（都是「界面看起来对、实际不工作」类）

1. **大纲浮动层永不出现（死锁）**：`TocAnchor` 是 `tocCount` 的唯一上报者，却挂在以
   `tocCount > 0` 为条件的浮层内部 → 浮层不渲染 → 无人上报 → 永远不渲染。
   修：在 `onRendered` 回调里直接数 `.doc-content` 的 `h1~h4` 并写入 `tocCount`。
2. **思维导图编辑页整页白屏**：为承载大纲浮层加的 `paddingRight` 中间层是 auto 高度，
   打断了 `height: 100%` 链 → 画布容器塌陷为 0 → `new MindMap()` 抛错 →
   **effect 内抛错导致 React 卸载整棵树**。修：中间层补 `height: '100%'`；
   并给画布初始化加「下一帧重试 + 降级提示态」，不再一错就白屏。
3. **阅读页正文字符数为 0（最严重）**：Vditor 默认从 `unpkg.com` 拉 `lute.min.js`，
   离线/内网下请求失败 → `after` 回调不触发 → 正文空白且**控制台零报错**。
   修：`scripts/copy-vditor-assets.mjs` 把 vditor 资源子集同步到 `public/vditor/dist`，
   组件统一 `cdn: '/vditor'`；用 `network requests` 验证非本地请求为 0。
4. `gofmt` 未格式化的两个测试文件已修。

# 第二轮：按需分包做到路由级（同日晚些）

在实测确认「重型库已懒加载」之后继续深挖，发现前一轮只做了三分之一。分三层做完：

| 阶段 | 入口 chunk | 入口 CSS | BookPage chunk |
| --- | --- | --- | --- |
| 本轮开始 | 1727 KB | 43 KB | 623 KB |
| 第 2 层（路由级 lazy）后 | **649 KB**（gzip 213 KB） | — | — |
| 第 3 层（拆漏网依赖）后 | 649 KB | **3.0 KB** | **216 KB** |

相对最初的 3819 KB，入口 chunk 累计 **-83%**。

- **第 2 层**：`App.tsx` 9 个页面全改 `lazy()` + `<LazyBoundary fill>`；布局保持静态（外壳先出现更好看）。
  `LazyBoundary` 新增 `fill` 属性（`height:'100%'`，占位居中在内容区而不是顶在左上角）。
- **CSS 一起挪**：`import 'vditor/dist/index.css'` 从 `main.tsx` 移入 `MarkdownView.tsx` /
  `VditorEditor.tsx`。入口 CSS 43 KB → 3.0 KB，`grep vditor` 入口 CSS 为 0。
- **第 3 层（关键，靠实测抓出来的两处漏网）**：
  1. `VditorEditor → VersionDrawer →（静态）MarkdownView`：4 个编辑器都会下载整个 Vditor，
     哪怕 docType 不是 markdown、哪怕从不看版本历史 → `VersionDrawer` 内改 lazy。
  2. `BookPage → DocTree →（静态）ImportDialog → lib/import/parse.ts → SheetJS/turndown/jszip`：
     打开任意知识库就下载 ~400 KB 导入解析代码 → `DocTree` 内改 lazy，且**只在 `importOpen` 时挂载**
     （ImportDialog 自带 `destroyOnClose`、effect 均以 `open` 为条件，延迟挂载不改变行为）。

**排查手法**：用特征字符串给 chunk「验明身份」——包名会被压缩掉，API 名不会
（`grep -l "sheet_to_json\|Workbook\|SSF" *.js` 找到 SheetJS 藏在 BookPage chunk 里）。

**新踩的坑**：
- 判断入口 chunk **必须**从 `index.html` 取文件名。dist 里有 12 个 `index-*.js`、2 个 `index-*.css`
  的内部共享 chunk，`grep -c 'assets/index-'` 会得到 4 而不是 1（我因此误判一次）。
- `agent-browser eval` 返回值**带引号**（`"true|2|false"`），断言前要 `tr -d '"'`，
  否则全线假失败。
- 本机 `/dev/fd` 被沙箱拦，`comm -13 <(a) <(b)` 报 `/dev/fd/63: No such file or directory`，
  改用临时文件 + `grep -Fxv -f`。

**回归**：ui-doc-types 18/18、ui-shot 全通过（非本地请求 0、控制台 0 错误）、
e2e-import 10/10、e2e_export 15/15、check-lazy-routes 14/14、check-route-fallback 14/14、
sim-docker-web `DOCKER_WEB_STAGE_OK`、Go 单测全绿、`gofmt -l` 空。
