## 修复 3 个 H5/表格 Bug + 分享阅读支持 H5（同一会话下半场）

### BUG1 · H5 阅读态纵向划屏不响应（MD/DOCX/PDF + 目录树）
- 根因：`web/src/index.css` 的 `html, body { overflow-x: hidden }` 按 CSS 规范会把 `overflow-y` 强制计算为 `auto`，
  使 `<body>` 变成滚动容器，嵌套 `overflow:auto` 的触屏滚动在 iOS Safari/微信内核失效 → 手机上划屏不动、目录树点不动。
- 修复：
  - `index.css`：`overflow-x: hidden` → `overflow-x: clip`（不创建滚动容器）；给 `.doc-content`、`.docx-preview` 加 `touch-action: pan-y`。
  - `h5/H5DocContainer.tsx`：内层滚动 div 的 `touchAction` 由 `editing ? 'none' : 'manipulation'` → `editing ? 'none' : 'pan-y'`。
  - `h5/MobileLayout.tsx`：`<main>` 滚动容器加 `touchAction: 'pan-y'`。
- 注：目录树在手机上不滚动的根因之一是分享页被强制套桌面双栏（见 BUG3/分享），本修复覆盖通用阅读场景。

### BUG2 · LuckySheet 阅读态二次点击单元格下偏移 ~6 行
- 根因：阅读态表格嵌在滚动文档流中，容器几何尺寸被缓存；二次点击落在 200ms 防抖 `refresh()` 窗口内、几何尚未重测，
  点击→单元格映射用旧几何 → A10 实际选 A16。编辑态容器 `height:100%` 固定、offset 恒定故无此 bug。
- 修复 `components/reader/SheetView.tsx`：
  - 200ms 防抖 `scheduleRefresh` 改为 `requestAnimationFrame` 立即重测；
  - 新增 `pointerdown` 捕获阶段 handler，在 Luckysheet 自身 mousedown 之前同步 `refresh()` 重测几何。
  - （`refresh()` 即 `id()`，仅重渲染不重测尺寸，故需勤触发。）
