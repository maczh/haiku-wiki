### 排查与修复
- **`<defs><defs>` 嵌套**：网格 pattern 用 `out.insert(2, "<defs>…")` 单独插，插进了箭头 defs 内部
  → 改为箭头 marker 与 pattern 合并进同一个 `<defs>`；并在生成器与套件两处加守卫。
- **mermaid 甘特整图落在过去**：20 个模板锚在 2026-01~05，mermaid 不会画 today 竖线，观感像作废排期表
  → 按 `polish.py` 的基准约定（2026-09-22 − 12 天）平移 18 个；「双十一大促」（锚 11-11）、
  「展会筹办」（跨到 10-14）语义绑定固定日历事件，自动识别并保留。
- **4 组模板同名**（在线教育课程 / 能源抄表计费 / 保险保单理赔 / SaaS多租户权限 在类图与 ER 图两侧同名）
  → 加「领域模型 / 数据模型」后缀消歧，并加 `TestBuiltinTemplateNamesUnique` 固化。
- **markdown JSON「不一致」假警报**：手工编辑过的 4 个 JSON 只是少了 `gen.py` 写的末尾换行，
  正文与源完全一致 → 跑一次 `gen.py` 收口即可（别再手改 JSON）。
- **`gen.py` 误收非 markdown 源目录**（`_src/flowchart`、`_src/drawing`）→ 加「目录内需有 `.md`」守卫。
- **契约澄清**：drawing 的 `xml` 是 draw.io **完整文件格式** `<mxfile><diagram><mxGraphModel>…`，
  不是裸 `<mxGraphModel>`；`import/parse.ts` 与 draw.io embed 的 `load` 两者通吃。
