### 1. 桌面表格阅读态「二次点击差 6 行」——根因是 CSS 包含块（不是时序）
- 探针实测：外层滚 156px 后宿主 rect.top 260→104，而 `#luckysheet-cell-main` 恒 280 →
  **网格压根没跟着滚**；点击 #1 selRow=4，#2/#3 selRow=10（Δ129px ≈ 6 行）。
- 根因：`luckysheet.css` 给根 `.luckysheet` 写的是 `position:absolute` 且**无 top/left**；
  宿主 div 是 `static` 时它的包含块落到滚动容器之外的定位祖先上。而 luckysheet 算命中行用
  `$("#"+container).offset().top`（宿主位置，随滚动走）→ 与网格原点脱钩。
- 修法：`reader/SheetView.tsx` 宿主 `box.style.position='relative'`。
- 顺带把「每次 pointerdown 都 refresh()」降级为漂移守卫（`|drift-20|>24` 才 refresh），避免整表重绘闪烁。
- 断言（`preview-zoom-check.sh` 第 5 段）：同一网格相对偏移连点 3 次 + 滚动 250px 后再点，4 次命中同一行。

### 2. DOCX/PDF H5 默认大小划不动、放大后反而能拖
- 判断是 iOS WebKit 嵌套 overflow 视口冲突（原实现只给 `minHeight`，滚动交给祖先）。
- `h5/H5ZoomStage.tsx` 改为**自己就是滚动视口**：`height:100%` + `overflow: zoomed?'hidden':'auto'`
  + `overscrollBehavior:contain` + `touchAction: zoomed?'none':'pan-x pan-y'`；
  `H5DocContainer` 相应传 `height:100%`（不能再用 minHeight）。

### 3. 思维导图 H5 放大虚化 → 原生无级缩放
- 根因：CSS `transform: scale()` 是把**已栅格化的位图**拉伸；`will-change:transform` 更糟（按 1:1 栅格化）。
- 改法：`reader/MindmapView.tsx` 新增 `attachNativeZoom()` 直接驱动 `mm.view.scale/x/y` + `view.transform()`，
  按比例重绘矢量 → 无级且始终清晰。算法与官方 `src/plugins/TouchEvent.js` 逐行一致
  （两指中心为锚、初始距离线性放大、位移<10px 视为抖动）。
- 配套：`h5/styles.ts` 的 `H5_ZOOMABLE_TYPES` **移除 mindmap**；加浮层「NNN% · 重置」；
  `types/vendor.d.ts` 补 `view.x/y/transform` + `toPos` 类型。
- 注意：`simple-mind-map` 的 TouchEvent 插件**只在 full.js 里注册**，我们引的是 index.js + 单插件，
  所以默认没有双指手势，自己挂不会冲突。

- H5 此前**完全没有新建能力**：写操作被显式置 no-op（`DocTreeDrawer` 的 `onNewDoc/onNewBook={noop}`）；仅 import FAB。
- 桌面新建 = `BookPage.openNewDoc` 两段式（画廊→选位置→填信息）；`createDoc(bookId,parentId,title?,docType?,content?)`
  → POST /books/:bookId/docs，建目录即 `doc_type:'folder'`。`DOC_TYPES` 白名单（types.ts）含 12 类 + `folder`。
- H5 阅读/编辑分发：`MDoc` 用 `editable = getDocMode==='editable' && canWrite`；`getDocMode` 白名单仅
  whiteboard/todo/calendar；`EDITOR_MAP` 三者；`READER_MAP` 全部 14 类。GalleryEditor Props=`{docId,content,onChanged?}`。

### 实现（按用户点名 5 类，覆盖软件工程师偏离 spec 的偏差：其方案误删 whiteboard/gallery，已否决）

  `handleCreated` 刷新树 + 文档类 `navigate('/m/doc/:id')`、目录类留在树中。`DocTreeList` 递归调用补 `onCreate`。

- 白板/待办/日历本就在白名单；图片库经上述接入后即「创建→自动进编辑态」。
