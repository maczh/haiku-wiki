### 关键 bug 修复
- **批量导入白屏根因**：`var failed []fileErr` 零值 nil slice → JSON `null` → 前端 `.length` TypeError 白屏。改为初始化 `[]`。
- **builtin 字段全错标**：原 `Builtin bool \`gorm:"default:true"\``，GORM 对带 default 字段跳过零值，自建/批量导入的模板全被写 `builtin=1` → 管理员删不掉、不进自定义列表。改为去掉 default、SeedTemplates 显式 `Builtin=true`、CreateTemplate/导入显式 `Builtin=false`。并加**启动幂等 repair**：把 `builtin=1` 但 `created_by>0` 的脏数据修正为 `builtin=0`。
