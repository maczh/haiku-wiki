## 一、产品概览

寄海文库把「知识库 → 目录树 → 文档」三级结构与「多种内容形态」合并在一个系统里，
用一套账号、一套权限、一套搜索覆盖团队日常的全部文档场景。

**核心能力一览**

| 分类 | 能力 |
| --- | --- |
| 组织 | 书架式知识库、多级目录树、拖拽排序、置顶、复制、跨库移动 |
| 内容 | 文档 / 表格 / 思维导图 / 流程图 / 绘图 / 待办清单 / 工作日历 / 甘特图 / 接口文档，共 9 种类型 |
| 附件 | Word、PDF、PPT、CAD 图纸（DWG/DXF）等原文件保存 + 内置预览 |
| 检索 | 标题 + 正文全文搜索，权限过滤，关键词高亮与上下文片段 |
| 协作 | 文档级协作者邀请、版本快照与回滚、团队与团队文库 |
| 分享 | 知识库分享、文档分享（可选密码 / 过期时间）、微信二维码分享 |
| 流转 | 12 类格式导入（含网页 URL 抓取）、服务端多格式导出、整库打包导出 |
| 运维 | 单容器部署、SQLite / MySQL 双选、全离线运行（无任何外部 CDN） |

## 二、快速开始

### 2.1 访问与登录

1. 浏览器打开部署地址（默认 `http://<服务器IP>:8080`）。
2. 使用管理员分配的账号登录；新成员可点击**注册**，填写邮箱、用户名、密码自助注册。
3. 系统**内置一个管理员账号** `admin`（初始密码 `Jihai2026`）。
   ⚠️ 首次登录后请立即在「账号设置 → 修改密码」中修改，避免默认口令长期暴露。

**新注册的账号一律是普通成员**（`role=member`）。管理员权限只能由现有管理员在数据库中调整，
不存在「第一个注册的人自动成为管理员」的机制。

登录状态保存在浏览器本地（`hk_token`），有效期为 7 天；过期后需重新登录。
同一 IP 注册有 60 秒频率限制（超限返回 `42901 注册过于频繁`）。

### 2.2 忘记密码

系统不提供自助找回。请联系管理员在「用户管理」中为你的账号**重置密码**。

### 2.3 建议的第一次操作路径

```
注册登录 → 首页查看新手向导 → 新建知识库 → 新建文档 → 编辑并等待自动保存
        → 拖拽调整目录结构 → 搜索验证 → 分享给同事 → 导出为 PDF/Word
```

## 三、界面总览

登录后进入主界面，自上而下分为两个区域：

**顶部导航栏（常驻）**

| 元素 | 作用 |
| --- | --- |
| 寄海文库 Logo | 点击任意时刻返回首页 |
| 搜索框 | 输入关键词后回车，进入搜索结果页 |
| 书本图标 | 返回「我的知识库」首页 |
| 团队图标 | 进入团队列表（团队文库与成员管理） |
| 垃圾桶图标 | 进入回收站 |
| 头像菜单 | 账号设置 / 用户管理（仅管理员可见）/ 退出登录 |

**内容区**：随路由切换，依次为首页 Dashboard、知识库页、搜索页、团队页、设置页、回收站等。

知识库页面采用**左右分栏**：左侧是可折叠、可拖拽调宽的文档目录树，右侧是阅读 / 编辑区域。

登录后的首页同时承担「入口」与「导航」两个职责。

### 4.1 页面结构

| 区块 | 说明 |
| --- | --- |

| 最近更新 | 按更新时间倒序列出你可读的最近文档（含受邀协作的文档），显示所属知识库、文档类型与相对更新时间，点击直接进入。数据来自 `GET /api/recent-docs`，已按读权限过滤 |
| 新手使用向导 | 三步上手引导（建库 → 建文档 → 分享协作），可关闭且会被记住 |
| 视频介绍 | 内置操作演示视频，含语音讲解，可关闭且会被记住 |

### 4.2 新手使用向导

首次进入首页时，向导以卡片形式展示在快捷操作下方，内容为三步：

1. **新建知识库**——为团队或项目建立独立空间，并选择可见性。
2. **新建文档**——在目录树中创建任意类型文档，编辑内容自动保存。
3. **分享与协作**——生成免登录分享链接，或邀请同事共同编辑。

**关闭方式**：点击卡片右上角的关闭按钮。关闭后不再出现。
如需重新查看，点击快捷操作区或欢迎条上的「新手向导」按钮即可再次打开。

> 关闭状态记录在浏览器本地（`hk_onboard_dismissed`），换浏览器或清理浏览器数据后会重新出现。

### 4.3 视频介绍

视频介绍卡片内嵌操作演示视频（MP4，含中文语音讲解与字幕），直观演示：

登录 → 新建知识库 → 新建与编辑文档 → 切换文档类型 → 全文搜索 → 分享 → 导出。

**关闭方式**：点击卡片右上角关闭按钮，或视频播放完成后点击「不再提示」。
关闭状态同样记录在浏览器本地（`hk_intro_video_dismissed`）。

## 五、知识库（书架）

知识库是文档的最外层容器，对应书架上的「一本书」。

### 5.1 三类知识库

| 分区 | 来源 | 说明 |
| --- | --- | --- |
| 我的知识库 | 自己创建 | 可编辑、可删除、可改可见性 |
| 团队知识库 | 所属团队内创建 | 团队 admin 可新建，成员按角色可见 |
| 公司知识库 | 管理员或获得授权的用户创建 | 全公司可读，写权限由管理员授权 |

### 5.2 新建知识库

首页右上角点击**新建知识库**，填写：

- **封面色**：卡片配色，便于在书架上一眼区分
- **知识库名称**：最多 128 字符
- **简介**：一句话说明用途（可选）
- **可见性**：私有 / 成员可见 / 公开（新建后仅 owner 可修改）

### 5.3 编辑与删除

在知识库卡片上**右键**即可打开编辑弹窗，可修改名称、简介、封面色，或删除整个知识库。
删除知识库时，其下全部文档会一并进入回收站。

### 5.4 名称过滤

书架页顶部的过滤框可按名称实时筛选三类知识库。

## 六、文档树操作

每个知识库内的文档以可拖拽的多级树组织。

### 6.1 新建文档 / 新建目录

知识库页左上方为**新建文档**按钮组：

- 主按钮：直接新建「文档」类型
- 下拉菜单：选择其余 8 种类型后命名创建
- 相邻的**导入**下拉：按文件类型导入

三个地方都能新建，且都能**指定存放位置**：

| 入口 | 位置 |
| --- | --- |
| 左侧目录树的知识库三横菜单 | 新建文档 / **新建目录** / 导入 |
| 任意节点右键 | 新建子文档 / **新建子目录** |
| 正文区空态 | 「新建文档 / **新建目录**」文字链接 |
| 首页 Dashboard 快捷操作 | 新建文档 / 导入文件 / 导入网页（同样可选目录） |

**新建目录**与新建文档共用第一步「选择位置」（知识库 + 目录），
第二步只填名称——目录不承载正文，因此没有类型可选。

### 6.2 右键菜单

在文档节点上右键可获得完整操作：

| 菜单项 | 说明 |
| --- | --- |
| 打开 | 进入阅读态 |
| 重命名 | 修改标题（需要写权限） |
| 编辑文档 | 切换到编辑模式（附件型与目录不可编辑） |
| 复制 | 在当前目录生成一份副本（目录不可复制） |
| 移动到其他知识库 | 跨库搬迁，保留子树结构 |
| 导出 | 打开导出面板（详见第十一节；目录不提供） |
| 分享 | 生成免登录分享链接（详见第十三节；目录不提供） |
| 邀请协作 | 添加协作者（详见第十四节；目录不提供） |
| 置顶 / 取消置顶 | 置顶后在同级中排最前，图标高亮 |
| 新建子文档 / 新建子目录 | 在其下创建子节点 |
| 删除（进回收站） | 软删除，整棵子树一并进回收站，可恢复 |

### 6.3 拖拽排序与移动

- 拖动节点可调整**同级顺序**，或拖到其他节点上变成其**子节点**；
- 排序使用 fractional indexing 算法，改动只写一个排序键，**写放大为 O(1)**，大目录下拖拽依然顺滑；
- 排序规则：**置顶节点永远在前**，其余按拖拽顺序。

### 6.4 目录树面板

- 顶栏按钮可**收起 / 展开**左侧目录树，把正文区放到最大；
- 目录树与正文之间的分隔条**可拖拽调宽**，宽度偏好会被记住。

### 6.5 目录（文件夹）

**目录**是一类特殊的节点（`doc_type=folder`）：它自己**不承载正文**，
只用于给文档分组分层——适合「按项目 / 按部门 / 按交付物」这类天然分层的信息。

- 树里恒以黄色文件夹图标显示（普通文档只有在「有子节点」时才显示成文件夹）；
- 可以任意嵌套：目录里放子目录、子文档，层级不限；
- 打开目录看到的是说明占位页，而不是空白编辑器；
- 目录**不参与**全文搜索、导出、「最近更新」与分享协作——它只是容器；
- 删除目录会把**整棵子树**一起移入回收站，恢复即可整棵回来。

> **新建 / 导入时的「目录（存放位置）」下拉**会列出当前知识库里的**全部层级**
> （缩进表示深度，目录带「（目录）」后缀），所以你可以把新文档、导入的文件
> 直接放到任意层的子目录或某个文档下面，不必先建到根目录再拖动。

## 七、九种文档类型与目录

「新建文档」时可选 9 种类型；此外「附件」由导入自动产生，「目录」由
「新建目录」入口产生（见 §6.5，它只是容器、没有正文）。

### 7.1 文档（Markdown）

- **编辑器**：Vditor 所见即所得（IR 模式），支持 Markdown 与富文本混合输入；
- 支持标题、列表、表格、引用、代码块、任务列表、图片粘贴上传、链接自动识别；
- 粘贴网页 URL 会自动抓取标题转为链接；
- **阅读渲染**：Vditor 预览管线 + DOMPurify 消毒，代码块语法高亮；
- **导出**：服务端 `.md` / `.docx` / `.pdf`，浏览器端另可生成 Word / 演示 / PDF（详见第十一节）。

### 7.2 表格

- 基于 Luckysheet 的在线电子表格，支持多工作表、公式、单元格样式；
- 新建即一张空白工作表，可直接粘贴 Excel 数据；
- **导出**：`.xlsx` / `.csv` / `.json`。

### 7.3 思维导图

- 基于 simple-mind-map，提供仿官方 Demo 的**浮动工具条**：插入子节点、同级节点、
  概要、关联线、图标、备注、标签；
- 支持公式（KaTeX）、主题配色、结构切换、缩放与拖拽画布；
- **导入**：`.smm` / `.km` / `.xmind` / `.mm` 可解析为内置格式；
- **导出**：`.km` / `.smm` / `.xmind` / `.mm` / `.png`。

### 7.4 流程图

- 使用 Mermaid 语法编写，实时渲染；
- **导出**：`.md`（内含 ```mermaid 源码）/ `.svg` / `.png`。

### 7.5 绘图

- 内嵌完整 **draw.io** 编辑器（本地自托管，离线可用）：形状库、素材库、对齐分布、
  图层、导入导出、历史快照齐备；
- 阅读态以只读方式内嵌预览，不加载完整编辑器；
- `.drawio` 文件导入后可直接继续编辑；
- `.vsd` / `.vsdx`（Visio）导入后先转换预览，可**另存为绘图文档**继续编辑；
- **导出**：`.drawio`（`.svg` / `.png` 在编辑器内导出）。

> ⚠️ `.vsdx` **只能导入、不能导出**，这是 draw.io 开源版的固有限制。

### 7.6 待办清单

- 列表式任务管理：事项内容、截止时间、优先级、备注；
- 支持行内编辑、勾选完成、删除；
- 底部输入框可快速追加，回车即录入。

### 7.7 工作日历

- 月历视图，按日期聚合任务；
- 点击日期查看当天安排，可直接在日历上**新建 / 修改 / 删除**任务；
- 任务支持标记完成、取消，并区分开始与结束时间。

### 7.8 甘特图

- 基于 SVAR Gantt 的进度管理视图，左表格 + 右时间轴；
- 支持父子任务（汇总条）、进度、优先级、负责人、说明等字段；
- 任务条按状态自动着色：**已结束 / 已超期 / 未开始 / 进度拖延 / 正常**；
- 优先级以紫罗兰外框透明度区分（P1 最浅 → P10 最深）；
- 悬停任务条显示气泡，展示任务详情与负责人；
- **左右面板均可折叠**：左侧表格、右侧时间轴可分别收起，把版面留给另一侧；
  折叠是「压到 0 宽」而非隐藏，行数据完整保留；
- 图表区域支持纵向滚动浏览大量任务；
- **权限**：有写权限时可在阅读态直接拖动进度手柄更新进度；无写权限时只读。

### 7.9 接口文档

面向 API 设计与联调场景：

- 分组管理接口，每个接口包含名称、描述、方法、路径、参数表（字段名 / 类型 / 中文名 / 说明）、
  请求与响应示例；
- **在线调试**：可在页面内直接发起请求并查看响应，服务端代理转发以绕开浏览器跨域限制；
- **调试历史**：同一接口保留最近 10 次调试记录，可一键回填；
- **导入**：支持 Swagger 2 / OpenAPI 3 / Apifox / Postman 集合，粘贴地址或 JSON 即可批量生成接口；
  - 导入时按接口的 `tags` 自动分组（Postman 按其文件夹结构分组），无 tag 时回退到文档标题；
  - **同一来源重复导入会整体替换旧分组**，不会越导越乱；手动新建的分组不受影响；
- **批量删除**：左栏「批量删除」进入勾选模式，可按行勾选或整组全选，确认后一次性删除；
- 支持复制 URI、复制完整 URL 到剪贴板。

### 7.10 附件（由导入产生）

导入的原始文件按**原文件保存**，正文不可编辑，但提供内置预览与下载：

| 附件格式 | 预览方式 |
| --- | --- |
| `.pdf` | pdf.js 分页渲染 |
| `.docx` / `.doc` | mammoth 转换为 HTML 展示 |
| `.pptx` | pptx-preview 逐页浏览，支持自动播放（3/5/10 秒）、全屏、键盘翻页 |
| `.dwg` / `.dxf` | 服务端转 SVG（矢量优先）+ PNG；支持滚轮缩放（以光标为锚点）、拖动平移、双击复位、`+`/`-`/`0`/方向键快捷键 |

CAD 图纸还可导出原图、SVG、PNG 三种形态。

### 7.11 目录（容器，非内容类型）

目录不列在「新建文档」的类型下拉里，因为它不是内容类型——它是**层级容器**。
用法与交互见 §6.5，这里只列它的技术语义，便于理解它在各处为什么「不出现」：

| 场景 | 目录的表现 |
| --- | --- |
| 落库 | `doc_type = folder`，`content` 恒为空 |
| 目录树 | 恒显示文件夹图标，可无限嵌套 |
| 搜索 | 不参与（没有正文可搜） |
| 导出 | 无可导出格式，导出入口直接不显示 |

## 八、编辑、自动保存与版本

### 8.1 自动保存

所有可编辑文档统一采用 **3 秒防抖自动保存**：停止输入 3 秒后自动写入；
切换文档或离开页面前会立即补一次落库，避免内容丢失。
编辑区右上角有保存状态指示器（保存中 / 已保存）。

### 8.2 版本快照

- 内容发生变化时**自动生成快照**，也可手动创建；
- 保留最近 **20 个版本**，超出后自动清理最旧的；
- 「历史版本」抽屉可查看每个快照的时间与摘要；
- 可**预览**任意版本内容，并一键**回滚**到该版本。

### 8.3 恢复与彻底删除

删除的文档进入回收站（软删除）。如需恢复单个已删除文档，可使用文档级「恢复」；
如需连同其历史快照一并清除，则使用「彻底删除」。

## 十、导入

### 10.1 本地文件导入

点击目录树顶部的**导入**按钮，支持多选与拖拽上传。
导入前可在「导入 · 选择位置」里指定**知识库 + 目录**：目录下拉列出该库的**全部层级**
（缩进表示深度，目录带「（目录）」后缀），选中后所有导入文件都会落到该层级。

| 源格式 | 导入结果 |
| --- | --- |
| `.md` / `.txt` | 文档 |
| `.html` | 文档（自动清洗标签） |
| `.xlsx` / `.xls` / `.csv` / `.et` | 表格；多工作表时以文件名建父节点，每个有内容的工作表作为子文档 |
| `.docx` / `.doc` | 附件（原文件保存 + 内置预览） |
| `.pdf` | 附件 |
| `.pptx` | 附件（支持逐页浏览与自动播放） |
| `.dwg` / `.dxf` | 附件（服务端转 SVG/PNG 矢量预览） |
| `.drawio` | 绘图 |
| `.vsd` / `.vsdx` | 绘图（转换预览，可另存为可编辑绘图文档） |
| `.smm` / `.km` / `.xmind` / `.mm` | 思维导图 |

上传有格式白名单与 **64MB** 单文件上限校验，不支持的扩展名会被友好拒绝且不产生任何文档。

### 10.2 网页导入

**导入网页**入口（首页快捷操作亦可进入）输入 URL，服务端抓取正文并转为 Markdown 文档。
该能力带 SSRF 防护，禁止访问内网地址，因此不能用于抓取内网系统。

### 10.3 导入结果与去重

- 导入目标为当前知识库的根目录，导入后可按需拖拽调整层级；
- 上传前会做**扩展名白名单前置校验**，不支持的类型直接友好拒绝，不解析、不上传、不创建文档；
- 单文件上限 **64MB**，超限返回 `41301`；
- 同名文件重复导入会在目录中生成新的节点，不会覆盖既有文档。

> 如果你导入的是 **Swagger / OpenAPI / Apifox / Postman 接口文档**，同一份来源重复导入会
> **整体替换**旧分组而不是产生重复，详见 [7.9 接口文档](#79-接口文档)。

## 十一、导出

导出走**两条互补路径**，同一个对话框里呈现，用户无需关心由谁完成：

- **服务端转换**（单一事实来源）：格式清单由后端接口下发
  （`GET /api/export/docs/:id/formats`），前端只负责保存返回的二进制流，前后端不会不一致；
- **浏览器端转换**：服务端做不了或做不好的排版型格式——Word `.docx`、演示 `.pptx` / `.ppts`、PDF `.pdf`，
  由浏览器直接生成，排版还原更好。

### 11.1 各类型可选格式

| 文档类型 | 服务端导出 | 浏览器端导出 |
| --- | --- | --- |
| 文档（markdown） | `.md` / `.docx` / `.pdf` | `.docx` / `.pptx` / `.ppts` / `.pdf` |
| 表格（sheet） | `.xlsx` / `.csv` / `.json` | 同上 |
| 思维导图 | `.km` / `.smm` / `.xmind` / `.mm` / `.md` / `.json` / `.png` | 同上 |
| 流程图 | `.md`（含 Mermaid 源码） / `.svg` / `.png` | 同上 |
| 绘图 | `.drawio`（`.svg` / `.png` 在 draw.io 编辑器内导出） | — |
| 待办清单 | `.xlsx` / `.md` / `.json` | 同上 |
| 工作日历 | `.xlsx` / `.ics` / `.json` | 同上 |
| 甘特图 | `.xlsx` / `.md` / `.json` | 同上 |
| 接口文档 | `.md` / `.json` | 同上 |
| 附件 | 原文件；CAD 图纸另有 `.svg` / `.png` | `.docx` 附件可转 `.pdf`；`.pptx` 附件可转 `.ppts` / `.pdf` |
| 整个知识库 | `.md.zip`（按目录结构打包） | — |

> `.ics` 日历文件可被手机系统日历直接订阅导入；`.json` 是各类文档的**原始数据结构**，
> 适合再加工或做数据迁移。

### 11.2 保存与命名

导出前可自定义文件名；浏览器支持 File System Access API 时会弹出系统「另存为」对话框，
否则降级为普通下载。整个知识库导出得到的是一个按原目录结构组织的 `.md.zip`，
其中附件按原文件打包、绘图导出为 `.drawio`。

## 十九、常见问题 FAQ

**Q1：我怎么知道自己是不是管理员？**
管理员登录后，头像菜单里会多出「用户管理」入口。系统内置一个 `admin` 账号，
新注册的账号一律是普通成员，不会自动获得管理员权限。

**Q2：忘记密码怎么办？**
系统不提供自助找回，请联系管理员在「用户管理」中重置。

**Q3：为什么某些文档我打不开？**
文档权限跟随所属知识库的可见性。私有库只有创建者与协作者可访问。

**Q4：编辑到一半关掉浏览器，内容会丢吗？**
不会。编辑采用 3 秒防抖自动保存，且切换文档与离开页面时会立即补一次落库。

**Q5：导入的 Word / PDF / PPT 为什么不能编辑？**
这类文件按**原文件保存**为「附件」类型，正文不可修改，但可在线预览与下载原文件。
若需编辑，请新建「文档」类型并粘贴内容。

**Q6：`.vsdx` 为什么导不出来？**
Visio 导出是 draw.io 商业版（Atlassian 版）的专属能力，开源发行版不含该导出模块。
系统支持 `.vsd` / `.vsdx` **导入**并转换预览，可另存为可编辑的绘图文档后继续编辑。

**Q7：甘特图折叠一侧面板后行数会变少吗？**
不会。折叠是「把面板压到 0 宽」而非隐藏，左右面板共享同一份数据视图，
折叠前后任务行数完全一致。

**Q8：导出为什么分服务端和浏览器两条路？**
纯数据类格式（`.md` / `.xlsx` / `.csv` / `.km` / `.ics` / `.json` 等）在服务端转换，
保证格式一致、可控、与浏览器无关；排版敏感型格式（Word、演示、PDF）由浏览器直接生成，
图片与版式还原更好。两条路都在同一个导出对话框里，用户无需区分。
所有中文字体随镜像分发，离线内网环境同样可以导出。

**Q9：搜索能搜到别人的私有文档吗？**
不能。搜索结果严格按权限过滤，公开知识库才支持匿名搜索。

**Q10：能离线使用吗？**
可以。系统**不依赖任何外部 CDN**，前端资源（Vditor、draw.io 等）全部随二进制分发，
可在完全隔离的内网运行。

**Q11：「目录」和「文档」有什么区别？为什么新建时选不到目录类型？**
目录是**容器**：它没有正文、不能编辑/导出/分享/搜索，只负责分层（详见 §6.5 与 §7.11）。
因此它不在「新建文档」的类型下拉里，而是独立的**新建目录**入口。
新建文档/导入时可以在「目录（存放位置）」里选中任意层级的目录或文档，
把内容直接落到目标位置——不用先建到根目录再拖。
