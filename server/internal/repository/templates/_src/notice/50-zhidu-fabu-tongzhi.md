# 制度发布通知

> **文档信息**：编号 XZ-2026-0930B · 发文部门 行政部 · 拟稿 郑亦航 · 签发 陈嘉禾 · 日期 2026-09-30

> **填写说明**：以下为虚构示例内容，套用后请替换为你的实际信息。

## 一、制度发布

为规范公司信息系统账号与权限的全生命周期管理，防范越权访问与账号外借风险，经总经理办公会审议通过，现发布《信息系统账号与权限管理办法（V3.0）》，自 2026 年 10 月 9 日起施行。

| 项目 | 内容 |
| --- | --- |
| 制度名称 | 信息系统账号与权限管理办法 |
| 版次 | V3.0（替代 V2.1） |
| 审议通过 | 2026-09-26 总经理办公会 |
| 生效日期 | 2026-10-09 |
| 解释部门 | 研发中心运维组 · 人力资源部 |

## 二、适用范围

本办法适用于星澜科技全体在职员工，以及在公司信息系统内开设账号的外包人员、实习生与外部顾问。涉及系统范围包括 OA 系统、云枢 CRM、星澜数据中台、代码托管平台及公司 VPN 通道。

> **提示**：外部人员账号一律采用实名制、限期制，最长有效期 90 天，到期未办理续期的账号系统将自动停用。

## 三、修订要点

相较 V2.1 版本，本次修订主要变化如下：一是新增账号申请与权限变更的统一线上入口，取消纸质审批；二是明确离职当日账号必须关停的硬性时限；三是首次引入权限季度复核机制；四是对共享账号、口令外借设定明确责任追究条款。

## 四、重点条款摘要

| 条款 | 核心要求 | 与 V2.1 的差异 |
| --- | --- | --- |
| 第五条 账号申请 | 通过 OA「权限申请」模块提交，直属上级与运维组双签 | 取消纸质表单 |
| 第九条 权限变更 | 岗位调整后 3 个工作日内完成权限重配 | 新增明确时限 |
| 第十二条 离职处理 | 离职当日 18:00 前关停全部账号 | 原为 3 个工作日 |
| 第十五条 定期复核 | 每季度末组织一次权限复核，出具复核报告 | 全新条款 |
| 第十八条 责任追究 | 账号外借造成损失的，追究本人及直属上级责任 | 处罚标准细化 |

制度执行过程中如遇条款歧义，由研发中心运维组会同人力资源部解释；修订建议可通过 OA 系统「制度反馈」入口提交。
