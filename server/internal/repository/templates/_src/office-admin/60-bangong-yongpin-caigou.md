2. 本次同类物品已比价三家（供应商报价分别为 5,120 元、4,952 元、5,380 元），选定 4,952 元的供应商；
3. 到货后由申请人验收数量与规格，验收合格后 3 个工作日内提交发票至财务部；
4. 供应商交付周期为合同签订后 5 个工作日，遇缺货按替代型号方案执行并报备行政部。
