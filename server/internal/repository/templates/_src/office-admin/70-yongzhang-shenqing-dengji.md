# 用章申请与登记台账

> **文档信息**：编号 YZ-2026-0208 · 管理部门 行政部 · 经办 郑亦航 · 会签 秦朗（法务） · 版本 V1.0 · 登记周期 2026 年 9 月

> **填写说明**：以下为虚构示例内容，套用后请替换为你的实际信息。

## 一、用章类型与适用范围

公司印章实行分类保管、专章专用。各类印章的适用范围与保管部门如下，超出适用范围的一律不予用印。

| 印章类型 | 适用范围 | 保管部门 | 保管人 |
| --- | --- | --- | --- |
| 公司公章 | 对外正式文件、证明、授权书 | 行政部 | 郑亦航 |
| 合同专用章 | 各类合同、协议、订单 | 行政部 | 郑亦航 |
| 财务专用章 | 票据、结算、银行往来文件 | 财务部 | 赵晓岚 |
| 法人名章 | 银行开户、工商登记、授权文件 | 财务部 | 赵晓岚 |
| 人事专用章 | 劳动合同、在职/离职证明 | 人力资源部 | 孙倩 |

> **提示**：公司公章与财务专用章不得由同一人保管；法人名章使用须经分管副总及以上批准。

## 二、申请与审批流

```mermaid
flowchart LR
  A[申请人提交用印申请] --> B[部门负责人审批]
  B --> C{文件类型}
  C -- 合同协议 --> D[法务合规审查]
  C -- 证明授权 --> E[行政部复核]
  D --> E
  E --> F{重大事项}
  F -- 是 --> G[分管副总审批]
  F -- 否 --> H[加盖印章]
  G --> H
  H --> I[登记台账并归档]
```

## 三、申请单要素

| 要素 | 填写要求 |
| --- | --- |
| 申请人信息 | 姓名、部门、联系方式，须为在职员工 |
| 用印事由 | 简明说明用途，如「与云枢 CRM 客户签署服务协议」 |
| 印章类型 | 按第一节适用范围选择，不得混用 |
| 文件名称与份数 | 须与实际文件一致，如《技术服务协议》一式 4 份 |
| 文件去向 | 收件方名称与送达方式 |
| 附件 | 上传文件定稿 PDF，含页码 |
| 审批记录 | 逐级审批意见与时间须完整 |

> **风险**：严禁在空白纸张、空白合同、内容未定稿文件上用印；确需预用印的，须经分管副总书面批准并登记预用印编号。

## 五、台账核对与归档

| 核对项 | 要求 | 责任人 |
| --- | --- | --- |
| 台账完整性 | 每笔用印均有对应申请单 | 郑亦航 |
| 附件一致性 | 归档文件与审批文件一致 | 郑亦航 |
| 月度汇总 | 每月末出具用印统计表 | 郑亦航 |
| 异常追查 | 台账与实物不符的当日核查 | 秦朗 |

用印登记台账保存期限不少于 5 年；涉及合同、授权的登记资料随合同档案一并长期保存。
