# 办公模板库（批量生成）

> 生成时间：2026-09-27 ｜ 共 **55 个 Word 模板 + 54 个 PPT 模板**
> 设计风格参考主流商用模板库的版式与视觉规范，全部为**原创可商用**模板（非下载版权素材）。

## 产出清单
- **Word 模板**：`generated_templates/word/`（55 个 .docx）
- **PPT 模板**：`generated_templates/ppt/`（54 个 .pptx）
- **分类索引**：`generated_templates/模板索引.md`

## 设计要点
- **10 套专业配色**：商务蓝 / 墨绿金 / 中国红 / 典雅紫 / 暖橙 / 青碧 / 极简灰 / 靛蓝 / 玫瑰红 / 森林绿，按序号循环，保证视觉多样性。
- **Word 通用版式**：主色封面横幅 + 金色分隔线 → 分节标题（▍ 色条）→ 键值表 / 专业表格（斑马纹 + 主色表头）→ 要点列表 → 浅底提示框 → 含页码与品牌的页脚。
- **PPT 通用版式**：渐变标题页（含装饰圆与品牌行）→ 目录页 → 主色分节页（巨型水印序号）→ 要点页 / 双栏页 / 数据卡片页 / 时间轴页 / 图片占位页 → 结尾致谢页；每页含页脚与页码。
- **即填即用**：正文以 `____` 占位，封面/表单含可替换的元信息字段。

## 覆盖场景（节选）
- **Word**：个人简历、求职信、入职登记、转正/辞职、通知、会议纪要、周/月/季/年报、工作总结、述职、合同（劳动/合作/保密/买卖/服务/租赁）、报价单、发票、报销单、立项/商业计划/营销/活动/培训方案、需求/验收/产品/用户手册、技术方案等。
- **PPT**：公司介绍、企业宣传、企业文化、团队介绍、年终/年度/季度/项目/述职汇报、产品/营销/品牌/活动/招商/竞品、商业计划/融资/创业路演、培训/入职/读书分享、数据分析/市场调研/战略/数字化/HR/财务、周年庆/团建/节日/新品发布/答谢、答辩/课题/创意提案等。

## 技术说明
- 基于 `python-docx` 与 `python-pptx` 以**数据驱动 DSL**批量生成（见 `gen/` 目录：`design.py` 设计系统、`word_engine.py` / `ppt_engine.py` 渲染引擎、`specs_word.py` / `specs_ppt.py` 场景定义、`gen_word.py` / `gen_ppt.py` 入口）。
- 重新生成：`cd gen && python gen_word.py && python gen_ppt.py && python gen_index.py`。
- 新增模板：在 `specs_word.py` / `specs_ppt.py` 的列表中追加一条即可，主题自动循环分配。
